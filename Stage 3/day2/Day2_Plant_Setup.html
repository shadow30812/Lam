Check before plugging the probes in. Red / brown / black isn't the usual DS18B20 colour code. Make sure the JST plug's pins line up with the TS header labels on the PCB (V, S, G or similar). A DS18B20 wired backwards gets hot within seconds: unplug it at once. Then type scan on ESP32 #2 (U7) and expect 1 sensor on each bus.

Before pressing START

  1. Empty 2 L jug standing inside T-5 under the red outlet. Mixing tank otherwise empty; mix 0 on ESP32 #1 (U2) if you emptied it since boot.
  2. Ice bath packed with ice and little water, coil fully covered. Spare ice ready.
  3. All ball valves open. Base tanks stirred.
  4. temps on ESP32 #1 (U2): both probes read. TT-1 at mid-depth in yellow, TT-2 in the flush tank.
  5. USB cable on ESP32 #1 (U2), pio device monitor running so the log file is written.
  6. When the log prints LIFT THE JUG OUT OF THE MIXING TANK NOW, lift it out. Step 2 lasts many minutes, so there is time.

Assumptions in this drawing

  • Tanks are filled to the organiser's level, so Step 2 has to cool about 10 L of yellow. Roughly 1.3 kg of ice melts, which should take about 20 to 40 minutes. That's an estimate, not a measurement.
  • The idle P2 and P4 block backflow (diaphragm pumps with check valves), so the cooling loop and the dosing line share TC without an extra valve.
  • The loop has no flow sensor. The firmware checks that TT-1 drops at least 0.3 °C in the first 3 minutes, and trips if it doesn't.
  • Each colour has its own tube into one of the three top holes of T-5. There's no shared header, so the one equal tee in use is TA and the spare equal tee is TC.
  • No float switches. Empty tank = no pulses on that line's flow sensor; full mixing tank / jug = volume count.
