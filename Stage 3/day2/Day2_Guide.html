Overview

Day 2 turns the Chocolate plant into one automatic sequence. A single press of START runs three steps, and each starts only when the one before reports DONE.

StepWhat the plant doesDONE when
1 FlushSV4 opens. P1 pulls water from the flush tank T-4 through tee TA and FT1 and out of the red outlet into the 2 L jug, which stands inside the mixing tank. FT1 totalises.FT1 reads 2,000 mL, P1 has switched itself off and SV4 is closed. The log says to lift the jug out
2 ΔTSV5 opens and P4 circulates yellow from the bottom of T-2 through the copper coil in the ice bath and back in at the top. TT-1 (yellow) and TT-2 (flush water) are read every 0.8 s.|TT-1 − TT-2| ≥ 10.3 °C on 3 readings in a row, P4 off, SV5 closed
3 DoseYellow 300 → Green 900 → Red 1,800 mL into T-5, each closed-loop on its own flow sensor with a slow finish.All three dosed, all pumps off, all five valves closed

The interlock trips every pump at once and closes every valve on no flow, an empty tank, a full mixing tank or jug, a lost sensor link, no cooling in the loop, or START pressed during the run. After the run, or a trip, the controller prints a report block with the four things the judges want: flush run, calibration table, ΔT trend and dosed volumes. tools/report.py turns the saved serial log into a page with charts.

Biggest unknown: how long Step 2 takes. The tanks are full, so the loop has to cool about 10 L of yellow by 10 °C. That is about 420 kJ, or roughly 1.3 kg of ice melted. With a small coil, expect about 20 to 40 minutes; this is an estimate, not a measurement. Time one cooling run with water on Day 2 morning (loop 1 and tlog 1) so you know.

Plumbing

  1. Red + flush: T-1 bottom → BV-1 → SV1 (arrow away from the tank) → TA run port. Flush tank bottom → BV-F → SV4 (arrow away from the tank) → TA side port. TA → P1 → FT1 (arrow with the flow) → T-5 left top hole.
  2. Green: T-3 bottom → BV-3 → P3 → FT3 → SV3 → T-5 middle top hole.
  3. Yellow (two-hole tank): bottom hole → BV-2 → TC. TC run port → P2 → FT2 → SV2 → T-5 right top hole.
  4. Cooling loop: TC side port → P4 → SV5 (arrow towards the coil) → coil inlet. Coil outlet → T-2 top hole, tube end above the liquid so it can't siphon. Coil fully under the ice.
  5. Tube ends in T-5 stay above the liquid. The 2 L jug stands under the red outlet for Step 1 only.
  6. Count: male 8 mm connectors 5 SV × 2 + 4 BV × 2 = 18 of 20. Equal tees TA and TC, both Y tees spare. The coil has its own push-fit ends.

Probe wiring check. Red / brown / black is not the usual DS18B20 colour code. Before plugging in, check that the JST plug pins match the TS header labels on the PCB. A DS18B20 wired backwards gets hot in seconds: unplug it at once. Then scan on ESP32 #2 (U7) should report 1 sensor on each bus. The PCB is assumed to have the data pull-up resistor; if scan finds nothing, add 4.7 kΩ from DATA to VDD.

Step 2 time and ice

Cooling needs 4.19 kJ per litre per °C, and melting ice absorbs 334 kJ/kg. For 10.3 °C:

Yellow in T-2Heat to removeIce melted (minimum)
6 L259 kJ0.8 kg
8 L345 kJ1.0 kg
10 L431 kJ1.3 kg

The 4.2 L bath holds about 3 kg of ice if packed, so it is enough for one run, but have spare ice. Stir the bath now and then: still water around the coil warms up and slows everything. Put TT-1 at mid-depth in T-2. Cold liquid sinks, so a probe on the bottom reaches ΔT sooner; whether that is fair is a question for the judges. Also ask whether the ice bath counts as one of "any two tanks": if so, ΔT is met almost at once.

Commissioning

  1. Valves on ESP32 #1 (U2): valve 1 1 then valve 4 1 should answer ! interlock: SV1 and SV4 may never be open together. Click-test SV2, SV3, SV5. Type off.
  2. Probes: scan on ESP32 #2 (U7), then temps on ESP32 #1 (U2) with both probes in the same water: within about 0.5 °C.
  3. Prime: jug under the red outlet, prime 4 10 (water) and prime 1 10 (red). Both should show flow on FT1.
  4. Water calibration of FT1 (required): empty jug, calrun 4 60, weigh (1 g = 1 mL), k 4 <mL>, then code and paste TUNE_K. In the simulation a 1.5 % k error put 1,969 mL in the jug while FT1 said 1,998.
  5. Cooling test: ice in the bath, tlog 1, loop 1. Check liquid comes back out of the coil into T-2 and TT-1 starts falling within a couple of minutes. Note the °C per minute. loop 0, tlog 0.
  6. Interlocks, with water: during prime 4 20 shut BV-F: P1 trips within about 2 s. Unplug TT-2, start: refused. Press START during a run: everything trips.
  7. Short full run: set tgt4 300, set tgt1 100, set tgt2 50, set tgt3 80, set dt 1, then START. Reboot afterwards to get the real values back.

The judged run

  1. Empty jug standing in T-5 under the red outlet. T-5 otherwise empty; mix 0 if you emptied it since boot.
  2. Ice bath packed, coil covered. Ball valves open. Base tanks stirred.
  3. status on ESP32 #1 (U2): link OK, all valves 0, both temperatures read, no last trip.
  4. Start the logging monitor. Press START once.
  5. When the log prints LIFT THE JUG OUT OF THE MIXING TANK NOW, lift it out. Cooling then runs for many minutes.

Assumptions and open points

  • Probe wiring: red = VDD, black = GND, brown = DATA is the likely mapping, not confirmed. Check against the PCB TS header before powering.
  • Which tanks: TT-1 in the cooled yellow tank, TT-2 in the flush-water tank. Any two tanks satisfy the rule; move TT-2 if a judge prefers.
  • Shared tee TC: idle diaphragm pumps block backflow, so the loop and the dosing line share TC without another valve. If P2 pulls air through the loop, close BV-2 briefly and re-prime with prime 2 5 (tube end in the jug).
  • No flow sensor on the loop: circulation is proven by TT-1 falling.
  • Cold yellow: slightly thicker, so FT2's k may shift a little. Recalibrate yellow with chilled liquid if there is time.
  • Jug in T-5: lifting it out after Step 1 is a manual action the judges have allowed.
  • Not compiled for the ESP32 here: the PlatformIO registry was blocked in this environment, so the code was checked with a host compiler against stub headers and a plant simulation (normal run, empty red tank, START as stop, missing probe, dead cooling loop, Step 2 skipped). Send any pio run error.

inline uint8_t linkChecksum(const char *s, size_t n) {
  uint8_t x = 0;
  for (size_t i = 0; i < n; i++) x ^= (uint8_t)s[i];
  return x;
}

inline int linkSeal(char *buf, size_t cap, int n) {
  uint8_t x = linkChecksum(buf, n);
  return n + snprintf(buf + n, cap - n, "%02X\n", x);
}

inline bool linkCheck(const char *buf) {
  const char *star = strchr(buf, '*');
  if (!star) return false;
  return (uint8_t)strtoul(star + 1, nullptr, 16) == linkChecksum(buf, star - buf + 1);
}

#include <Arduino.h>
#include <OneWire.h>
#include <DallasTemperature.h>
#include "link.h"

static const uint8_t FS_PIN[3] = {33, 25, 26};
static const uint8_t TS_PIN[2] = {32, 13};
static const uint8_t FSW_PIN[2] = {34, 35};
static const uint8_t H1_PIN = 23;
static const uint32_t TEMP_CONV_MS = 800;

static volatile uint32_t pulses[3] = {0, 0, 0};
static volatile uint32_t lastEdgeUs[3] = {0, 0, 0};
static const uint32_t MIN_EDGE_US = 300;

static void IRAM_ATTR countEdge(uint8_t i) {
  uint32_t now = micros();
  if (now - lastEdgeUs[i] >= MIN_EDGE_US) {
    pulses[i]++;
    lastEdgeUs[i] = now;
  }
}
static void IRAM_ATTR isr0() { countEdge(0); }
static void IRAM_ATTR isr1() { countEdge(1); }
static void IRAM_ATTR isr2() { countEdge(2); }

static portMUX_TYPE mux = portMUX_INITIALIZER_UNLOCKED;
static void snapshot(uint32_t out[3]) {
  portENTER_CRITICAL(&mux);
  for (int i = 0; i < 3; i++) out[i] = pulses[i];
  portEXIT_CRITICAL(&mux);
}

static OneWire bus1(TS_PIN[0]);
static OneWire bus2(TS_PIN[1]);
static DallasTemperature ds1(&bus1);
static DallasTemperature ds2(&bus2);
static int found1 = 0, found2 = 0;
static DeviceAddress addr[2];
static bool have[2] = {false, false};
static DallasTemperature *busOf[2] = {&ds1, &ds2};
static float tempC[2] = {NAN, NAN};
static uint32_t tempSeq = 0;


static uint32_t seq = 0;
static bool watch = false;

static bool validT(float t) { return !isnan(t) && t > -55.0f && t < 125.0f && t != 85.0f; }

static void scanSensors() {
  ds1.begin();
  ds2.begin();
  found1 = ds1.getDeviceCount();
  found2 = ds2.getDeviceCount();
  have[0] = found1 > 0 && ds1.getAddress(addr[0], 0);
  busOf[0] = &ds1;
  if (found2 > 0) {
    have[1] = ds2.getAddress(addr[1], 0);
    busOf[1] = &ds2;
  } else {
    have[1] = found1 > 1 && ds1.getAddress(addr[1], 1);
    busOf[1] = &ds1;
  }
  ds1.setResolution(12);
  ds2.setResolution(12);
  ds1.setWaitForConversion(false);
  ds2.setWaitForConversion(false);
  ds1.requestTemperatures();
  ds2.requestTemperatures();
}

static void readTemps() {
  float a = have[0] ? busOf[0]->getTempC(addr[0]) : NAN;
  float b = have[1] ? busOf[1]->getTempC(addr[1]) : NAN;
  tempC[0] = validT(a) ? a : NAN;
  tempC[1] = validT(b) ? b : NAN;
  tempSeq++;
  ds1.requestTemperatures();
  ds2.requestTemperatures();
}

static void sendTemps() {
  char buf[80];
  long a = validT(tempC[0]) ? lroundf(tempC[0] * 100) : TEMP_INVALID;
  long b = validT(tempC[1]) ? lroundf(tempC[1] * 100) : TEMP_INVALID;
  int n = snprintf(buf, sizeof(buf), "T,%lu,%ld,%ld,0*", (unsigned long)tempSeq, a, b);
  linkSeal(buf, sizeof(buf), n);
  Serial2.print(buf);
}

static void printTemps() {
  Serial.printf("TS1 (G32, %d found) %s  TS2 (G13, %d found) %s  dT %s\n", found1,
                validT(tempC[0]) ? String(tempC[0], 2).c_str() : "--", found2,
                validT(tempC[1]) ? String(tempC[1], 2).c_str() : "--",
                validT(tempC[0]) && validT(tempC[1]) ? String(fabsf(tempC[0] - tempC[1]), 2).c_str() : "--");
}

void setup() {
  pinMode(H1_PIN, OUTPUT);
  digitalWrite(H1_PIN, LOW);
  Serial.begin(115200);
  Serial2.begin(LINK_BAUD, SERIAL_8N1, LINK_RX_PIN, LINK_TX_PIN);
  for (int i = 0; i < 3; i++) pinMode(FS_PIN[i], INPUT_PULLUP);
  for (int i = 0; i < 2; i++) pinMode(FSW_PIN[i], INPUT);
  attachInterrupt(digitalPinToInterrupt(FS_PIN[0]), isr0, FALLING);
  attachInterrupt(digitalPinToInterrupt(FS_PIN[1]), isr1, FALLING);
  attachInterrupt(digitalPinToInterrupt(FS_PIN[2]), isr2, FALLING);
  scanSensors();
  Serial.printf("\n[U7 sensor, Day 2] FS1=G33 FS2=G25 FS3=G26  TS1=G32 (%d DS18B20)  TS2=G13 (%d DS18B20)\n", found1, found2);
  Serial.println(F("Commands: show, watch, temps, scan"));
}

void loop() {
  static uint32_t nextFrame = 0, nextWatch = 0, nextTemp = TEMP_CONV_MS;
  static uint32_t prevWatch[3] = {0, 0, 0};
  uint32_t now = millis();

  if ((int32_t)(now - nextTemp) >= 0) {
    nextTemp = now + TEMP_CONV_MS;
    readTemps();
    sendTemps();
  }

  if ((int32_t)(now - nextFrame) >= 0) {
    nextFrame = now + LINK_PERIOD_MS;
    uint32_t c[3];
    snapshot(c);
    int fsw = (digitalRead(FSW_PIN[0]) ? 1 : 0) | (digitalRead(FSW_PIN[1]) ? 2 : 0);
    char buf[80];
    int n = snprintf(buf, sizeof(buf), "F,%lu,%lu,%lu,%lu,%d*", (unsigned long)seq++,
                     (unsigned long)c[0], (unsigned long)c[1], (unsigned long)c[2], fsw);
    linkSeal(buf, sizeof(buf), n);
    Serial2.print(buf);
  }

  if (watch && (int32_t)(now - nextWatch) >= 0) {
    nextWatch = now + 500;
    uint32_t c[3];
    snapshot(c);
    Serial.printf("FS1 %lu (%lu Hz)  FS2 %lu (%lu Hz)  FS3 %lu (%lu Hz)  ",
                  (unsigned long)c[0], (unsigned long)((c[0] - prevWatch[0]) * 2),
                  (unsigned long)c[1], (unsigned long)((c[1] - prevWatch[1]) * 2),
                  (unsigned long)c[2], (unsigned long)((c[2] - prevWatch[2]) * 2));
    printTemps();
    for (int i = 0; i < 3; i++) prevWatch[i] = c[i];
  }

  static String rx;
  bool gotLine = false;
  while (Serial.available() && !gotLine) {
    char ch = Serial.read();
    if (ch == '\n' || ch == '\r') gotLine = rx.length() > 0;
    else if (rx.length() < 40) rx += ch;
  }
  if (gotLine) {
    String cmd = rx;
    rx = "";
    cmd.trim();
    if (cmd == "show") {
      uint32_t c[3];
      snapshot(c);
      Serial.printf("FS1 %lu  FS2 %lu  FS3 %lu  FSW5 %d  FSW6 %d\n", (unsigned long)c[0], (unsigned long)c[1],
                    (unsigned long)c[2], digitalRead(FSW_PIN[0]), digitalRead(FSW_PIN[1]));
    } else if (cmd == "watch") {
      watch = !watch;
      Serial.printf("watch %s\n", watch ? "on" : "off");
    } else if (cmd == "temps") {
      printTemps();
    } else if (cmd == "scan") {
      scanSensors();
      Serial.printf("TS1 bus: %d sensor(s), TS2 bus: %d sensor(s)\n", found1, found2);
    } else if (cmd.length()) {
      Serial.println(F("commands: show, watch, temps, scan"));
    }
  }
}

{

  {
    setDefaults();

static bool valveOpen[NSV] = {false};
static uint8_t pumpPct[4] = {0};
static uint32_t pumpOnMs[4] = {0};

static void writePump(int p, uint8_t pct)
{
  if (pct && !pumpPct[p])
    pumpOnMs[p] = millis();
  pumpPct[p] = pct;
  ledcWrite(p, (uint32_t)pct * ((1u << PWM_BITS) - 1) / 100);
}
static void writeValve(int v, bool open)
{
  digitalWrite(SV_PIN[v], open ? HIGH : LOW);
  valveOpen[v] = open;
}
static void pumpsOff()
{
  for (int p = 0; p < 4; p++)
    writePump(p, 0);
}
static void allOff()
{
  pumpsOff();
  delay(100);
  for (int v = 0; v < NSV; v++)
    writeValve(v, false);
}
static bool anyPump()
{
  for (int p = 0; p < 4; p++)
    if (pumpPct[p])
      return true;
  return false;
}

static bool pathOk(int p)
{
  if (p == P_RED)
    return valveOpen[SV_RED_SRC] != valveOpen[SV_WATER_SRC];
  if (p == P_YEL)
    return valveOpen[SV_YEL];
  if (p == P_GRN)
    return valveOpen[SV_GRN];
  return valveOpen[SV_LOOP];
}
static int pumpOfValve(int v)
{
  if (v == SV_YEL)
    return P_YEL;
  if (v == SV_GRN)
    return P_GRN;
  if (v == SV_LOOP)
    return P_LOOP;
  return P_RED;
}

static bool setPump(int p, uint8_t pct)
{
  if (pct > 100)
    pct = 100;
  if (pct > 0 && !pathOk(p))
  {
    if (p == P_RED)
      Serial.println(F("! interlock: P1 needs exactly one of SV1 (red) / SV4 (water) open"));
    else
      Serial.printf("! interlock: P%d needs SV%d open\n", p + 1, p == P_LOOP ? 5 : p + 1);
    return false;
  }
  writePump(p, pct);
  return true;
}
static bool setValve(int v, bool open)
{
  if (open && ((v == SV_RED_SRC && valveOpen[SV_WATER_SRC]) || (v == SV_WATER_SRC && valveOpen[SV_RED_SRC])))
  {
    Serial.println(F("! interlock: SV1 and SV4 may never be open together (water would run into the red tank)"));
    return false;
  }
  int p = pumpOfValve(v);
  if (!open && pumpPct[p])
  {
    writePump(p, 0);
    delay(100);
  }
  writeValve(v, open);
  return true;
}

static uint32_t counts[3] = {0, 0, 0};
static uint32_t lastCountChangeMs[3] = {0, 0, 0};
static uint8_t fswU7 = 3;
static uint32_t lastFrameMs = 0, framesOk = 0, framesBad = 0;
static bool linkOk() { return framesOk > 0 && millis() - lastFrameMs < 150; }

static float tempC[2] = {NAN, NAN};
static uint32_t lastTempMs = 0, tempFrames = 0;
static bool tempsOk() { return tempFrames > 0 && millis() - lastTempMs < 3000 && !isnan(tempC[0]) && !isnan(tempC[1]); }
static float deltaT() { return fabsf(tempC[0] - tempC[1]); }

static void pollLink()
{
  static char buf[96];
  static uint8_t n = 0;
  while (Serial2.available())
  {
    char c = Serial2.read();
    if (c == '\n')
    {
      buf[n] = 0;
      unsigned long seq, a, b, d;
      int f, h;
      long t1, t2;
      if (buf[0] == 'F' && linkCheck(buf) && sscanf(buf, "F,%lu,%lu,%lu,%lu,%d", &seq, &a, &b, &d, &f) == 5)
      {
        uint32_t nc[3] = {(uint32_t)a, (uint32_t)b, (uint32_t)d};
        uint32_t now = millis();
        for (int i = 0; i < 3; i++)
        {
          if (nc[i] != counts[i])
            lastCountChangeMs[i] = now;
          counts[i] = nc[i];
        }
        fswU7 = (uint8_t)f;
        lastFrameMs = now;
        framesOk++;
      }
      else if (buf[0] == 'T' && linkCheck(buf) && sscanf(buf, "T,%lu,%ld,%ld,%d", &seq, &t1, &t2, &h) == 4)
      {
        tempC[0] = t1 <= TEMP_INVALID ? NAN : t1 / 100.0f;
        tempC[1] = t2 <= TEMP_INVALID ? NAN : t2 / 100.0f;
        lastTempMs = millis();
        tempFrames++;
      }
      else
      {
        framesBad++;
      }
      n = 0;
    }
    else if (c != '\r')
    {
      if (n < sizeof(buf) - 1)
        buf[n++] = c;
      else
        n = 0;
    }
  }
}

static bool tlogIdle = false;

static void logTemp(bool force)
{
  static uint32_t next = 0;
  uint32_t now = millis();
  if (!force && (int32_t)(now - next) < 0)
    return;
  next = now + TUNE_TLOG_MS;
  if (!runLogging && !tlogIdle)
    return;
  float t = runLogging ? runSecs() : now / 1000.0f;
  uint8_t loopOn = pumpPct[P_LOOP] ? 1 : 0;
  Serial.printf("T,%.1f,%.2f,%.2f,%.2f,%d\n", t, tempC[0], tempC[1], deltaT(), loopOn);
  if (!runLogging)
    return;
  if (tTick++ % tStride)
    return;
  if (nT >= MAX_T)
  {
    for (int i = 0; i < MAX_T / 2; i++)
      tlog[i] = tlog[i * 2];
    nT = MAX_T / 2;
    tStride *= 2;
  }
  tlog[nT++] = {t, tempC[0], tempC[1], loopOn};
}

enum Phase
{
  D_IDLE,
  D_OPEN,
  D_FAST,
  D_SLOW,
  D_STOP,
  D_SETTLE,
  D_DONE,
  D_FAULT
};
static const char *PHASE_NAME[] = {"idle", "open", "fast", "slow", "stop", "settle", "done", "FAULT"};

static const uint32_t VALVE_MS = 200;
static const uint32_t STOP_TO_CLOSE_MS = 150;
static const uint32_t SETTLE_MS = 800;
static const uint32_t START_STALL_MS = 4000;
static const uint32_t STALL_MS = 2000;
static const uint32_t MAX_DOSE_MS = 600000;
static const uint32_t SLOW_BOOST_MS = 700;

struct Dose
{
  Phase ph = D_IDLE;
  int line = 0;
  float target = 0;
  bool timed = false;
  uint32_t runMs = 0;
  uint8_t duty = 0;
  bool toJug = false;
  uint32_t t0 = 0, tPh = 0, startCount = 0, lastPulseMs = 0, lastCount = 0;
  float mlAtStop = 0, mlFinal = 0;
  uint32_t pulsesFinal = 0;
  char fault[72] = "";
} dose;

static uint32_t lastPulses[NLINES] = {0, 0, 0, 0};
static uint32_t lastRunMs[NLINES] = {0, 0, 0, 0};
static float jugMl = 0, mixMl = 0;

static int sensorOf(int line) { return LD[line].sensor; }
static int pumpOf(int line) { return LD[line].pump; }
static float mlOf(int line, uint32_t pulses) { return cfg.line[line].k > 0 ? pulses / cfg.line[line].k : 0; }
static uint32_t dosePulses() { return counts[sensorOf(dose.line)] - dose.startCount; }
static bool doseActive() { return dose.ph != D_IDLE && dose.ph != D_DONE && dose.ph != D_FAULT; }

enum Seq
{
  S_IDLE,
  S_FLUSH,
  S_DT,
  S_DOSE,
  S_DONE,
  S_FAULT
};
static const char *SEQ_NAME[] = {"idle", "STEP 1 flush", "STEP 2 dT (cooling loop)", "STEP 3 dose", "done", "FAULT"};
static Seq seq = S_IDLE;
static char tripWhy[80] = "";

static void printReport();

static void trip(const char *why)
{
  pumpsOff();
  delay(100);
  for (int v = 0; v < NSV; v++)
    writeValve(v, false);
  if (doseActive())
  {
    dose.ph = D_FAULT;
    strncpy(dose.fault, why, sizeof(dose.fault) - 1);
  }
  strncpy(tripWhy, why, sizeof(tripWhy) - 1);
  bool wasRun = seq != S_IDLE && seq != S_DONE && seq != S_FAULT;
  if (wasRun)
    seq = S_FAULT;
  Serial.printf("!,TRIP,%.1f,%s\n", runLogging ? runSecs() : millis() / 1000.0f, why);
  Serial.printf("! INTERLOCK TRIP: %s. All pumps off, all valves closed.\n", why);
  if (wasRun)
  {
    Serial.printf("S,%.1f,FAULT,%s\n", runSecs(), why);
    runLogging = false;
    printReport();
  }
}

static bool loopStart()
{
  for (int v = 0; v < NSV; v++)
    if (valveOpen[v] && v != SV_LOOP)
      setValve(v, false);
  setValve(SV_LOOP, true);
  delay(VALVE_MS);
  return setPump(P_LOOP, cfg.loopDuty);
}
static void loopStop()
{
  writePump(P_LOOP, 0);
  delay(STOP_TO_CLOSE_MS);
  setValve(SV_LOOP, false);
}

static bool doseBegin(int line, float target, bool toJug, bool timed, uint32_t runMs, uint8_t duty)
{
  pollLink();
  if (!linkOk())
  {
    Serial.println(F("! no data from sensor board U7, check UART wiring and that U7 is powered"));
    return false;
  }
  if (!timed && cfg.line[line].k <= 0)
  {
    Serial.printf("! %s not calibrated (k=0). Run calrun/k first.\n", LD[line].name);
    return false;
  }
  if (toJug && (jugMl + (timed ? 0 : target) > cfg.jugMaxMl))
  {
    Serial.printf("! jug would overflow (now ~%.0f mL). Empty it and type: jug 0\n", jugMl);
    return false;
  }
  if (!toJug && !timed && mixMl + target > cfg.mixMaxMl)
  {
    Serial.printf("! mixing tank would pass %.0f mL (now ~%.0f mL). Empty it and type: mix 0\n", cfg.mixMaxMl, mixMl);
    return false;
  }
  if (pumpPct[P_LOOP])
    loopStop();
  for (int v = 0; v < NSV; v++)
    if (valveOpen[v])
      setValve(v, false);
  dose = Dose();
  dose.line = line;
  dose.target = target;
  dose.timed = timed;
  dose.runMs = runMs;
  dose.duty = duty;
  dose.toJug = toJug;
  setValve(LD[line].valveA, true);
  dose.startCount = dose.lastCount = counts[sensorOf(line)];
  dose.t0 = dose.tPh = dose.lastPulseMs = millis();
  dose.ph = D_OPEN;
  const char *where = toJug ? "into the JUG (jug must sit under the red outlet)" : "into the MIXING TANK";
  if (timed)
    Serial.printf("> run %s %lu ms at %u%% (%s)\n", LD[line].name, (unsigned long)runMs, duty, where);
  else
    Serial.printf("> dose %s %.1f mL (%s)\n", LD[line].name, target, where);
  return true;
}

static void doseTelemetry(uint32_t now)
{
  static uint32_t nextT = 0, prevCount = 0, prevMs = 0, nextStore = 0;
  if (dose.ph < D_FAST || dose.ph > D_SETTLE || (int32_t)(now - nextT) < 0)
    return;
  nextT = now + 250;
  uint32_t p = dosePulses();
  if (p < prevCount || now - prevMs > 1000)
    prevMs = 0;
  float rate = (prevMs && now > prevMs) ? mlOf(dose.line, p - prevCount) * 1000.0f / (now - prevMs) : 0;
  prevCount = p;
  prevMs = now;
  float ml = mlOf(dose.line, p);
  float t = runLogging ? runSecs() : (now - dose.t0) / 1000.0f;
  Serial.printf("D,%.2f,%d,%s,%u,%lu,%.1f,%.1f\n", t, dose.line + 1, PHASE_NAME[dose.ph],
                pumpPct[pumpOf(dose.line)], (unsigned long)p, ml, rate);
  if (runLogging && (int32_t)(now - nextStore) >= 0 && nD < MAX_D)
  {
    nextStore = now + 500;
    dlog[nD++] = {t, (uint8_t)(dose.line + 1), pumpPct[pumpOf(dose.line)], ml, rate};
  }
}

static void doseStep()
{
  if (!doseActive())
    return;
  uint32_t now = millis();
  LineCfg &L = cfg.line[dose.line];
  int pump = pumpOf(dose.line);
  uint32_t c = counts[sensorOf(dose.line)];
  if (c != dose.lastCount)
  {
    dose.lastCount = c;
    dose.lastPulseMs = now;
  }
  uint32_t p = dosePulses();
  float ml = mlOf(dose.line, p);

  if (dose.ph <= D_SLOW && !linkOk())
  {
    trip("lost sensor link");
    return;
  }
  if (now - dose.t0 > MAX_DOSE_MS)
  {
    trip("dose took too long");
    return;
  }
  if (!dose.timed && dose.toJug && jugMl + ml > cfg.jugMaxMl)
  {
    trip("jug full");
    return;
  }
  if (!dose.timed && !dose.toJug && mixMl + ml > cfg.mixMaxMl)
  {
    trip("mixing tank full (volume count)");
    return;
  }
  if (dose.ph == D_FAST || dose.ph == D_SLOW)
  {
    uint32_t limit = (p == 0) ? START_STALL_MS : STALL_MS;
    if (dose.ph == D_SLOW && now - dose.lastPulseMs > SLOW_BOOST_MS && pumpPct[pump] < L.fast)
    {
      int up = pumpPct[pump] + 10;
      uint8_t d = up > L.fast ? L.fast : (uint8_t)up;
      writePump(pump, d);
      L.slow = d;
      dose.lastPulseMs = now;
      Serial.printf("~ %s slow duty stalled the pump, raised to %u%% (now slow%d = %u; type code to keep it)\n",
                    LD[dose.line].name, d, dose.line + 1, d);
    }
    else if (now - dose.lastPulseMs > limit)
    {
      char why[72];
      snprintf(why, sizeof(why), "%s: %s", LD[dose.line].name,
               p == 0 ? "no flow after start (empty tank, air, valve shut?)" : "flow stopped (tank empty or pump stalled)");
      trip(why);
      return;
    }
  }
  doseTelemetry(now);

  float band = max(dose.target * cfg.bandPct / 100.0f, cfg.bandMinMl);
  float stopAt = dose.target - L.overrun;

  switch (dose.ph)
  {
  case D_OPEN:
    if (now - dose.tPh >= VALVE_MS)
    {
      uint8_t d = dose.timed ? dose.duty : L.fast;
      if (!dose.timed && ml >= dose.target - band)
        d = L.slow;
      if (!setPump(pump, d))
      {
        trip("interlock refused pump start");
        return;
      }
      dose.ph = (d == L.slow && !dose.timed) ? D_SLOW : D_FAST;
      dose.tPh = now;
      dose.lastPulseMs = now;
    }
    break;
  case D_FAST:
    if (dose.timed)
    {
      if (now - dose.tPh >= dose.runMs)
        goto stop;
    }
    else if (ml >= stopAt)
    {
      goto stop;
    }
    else if (ml >= dose.target - band)
    {
      writePump(pump, L.slow);
      dose.ph = D_SLOW;
      dose.tPh = now;
    }
    break;
  case D_SLOW:
    if (ml >= stopAt)
      goto stop;
    break;
  case D_STOP:
    if (now - dose.tPh >= STOP_TO_CLOSE_MS)
    {
      setValve(LD[dose.line].valveA, false);
      dose.ph = D_SETTLE;
      dose.tPh = now;
    }
    break;
  case D_SETTLE:
    if (now - dose.tPh >= SETTLE_MS && now - dose.lastPulseMs >= 300)
    {
      dose.pulsesFinal = p;
      dose.mlFinal = ml;
      lastPulses[dose.line] = p;
      lastRunMs[dose.line] = dose.timed ? dose.runMs : now - dose.t0;
      if (dose.toJug)
        jugMl += ml;
      else
        mixMl += ml;
      if (dose.timed)
      {
        Serial.printf("= calrun %s: %lu pulses in %lu ms (%.1f Hz). Now weigh the collected liquid and type: k %d <mL>\n",
                      LD[dose.line].name, (unsigned long)p, (unsigned long)dose.runMs,
                      p * 1000.0f / dose.runMs, dose.line + 1);
      }
      else
      {
        float coast = dose.mlFinal - dose.mlAtStop;
        if (cfg.learn && coast >= 0 && coast < 50)
          L.overrun = 0.5f * L.overrun + 0.5f * coast;
        Serial.printf("= %s target %.1f mL, metered %.1f mL (error %+.1f mL, %+.2f %%), coast %.1f mL, next overrun %.1f mL, pulses %lu, %.1f s\n",
                      LD[dose.line].name, dose.target, dose.mlFinal, dose.mlFinal - dose.target,
                      (dose.mlFinal - dose.target) * 100.0f / dose.target, coast, L.overrun, (unsigned long)p,
                      (now - dose.t0) / 1000.0f);
      }
      dose.ph = D_DONE;
    }
    break;
  default:
    break;
  }
  return;
stop:
  writePump(pump, 0);
  dose.mlAtStop = ml;
  dose.ph = D_STOP;
  dose.tPh = now;
}

static bool floatAlarm(uint8_t level) { return level == TUNE_FLOAT_ALARM_LEVEL; }

static void interlocks()
{
  uint32_t now = millis();
  if (anyPump() && !linkOk())
  {
    trip("lost sensor link while a pump was running");
    return;
  }
  for (int i = 0; i < 4; i++)
  {
    if (!TUNE_FLOAT_LOW[i] || !floatAlarm(digitalRead(FSW_PIN[i])))
      continue;
    bool feeding = (i == 0 && pumpPct[P_RED] && valveOpen[SV_RED_SRC]) || (i == 1 && (pumpPct[P_YEL] || pumpPct[P_LOOP])) ||
                   (i == 2 && pumpPct[P_GRN]) || (i == 3 && pumpPct[P_RED] && valveOpen[SV_WATER_SRC]);
    if (feeding)
    {
      char why[48];
      snprintf(why, sizeof(why), "low level float FSW%d (%s tank empty)", i + 1, LD[i].name);
      trip(why);
      return;
    }
  }
  if (TUNE_FLOAT_MIX_FULL && floatAlarm((fswU7 & 1) ? HIGH : LOW) && anyPump())
  {
    trip("mixing tank full (float FSW5)");
    return;
  }
  if (!doseActive())
  {
    for (int p = 0; p < 3; p++)
    {
      if (!pumpPct[p])
        continue;
      int s = p;
      uint32_t since = max(pumpOnMs[p], lastCountChangeMs[s]);
      uint32_t lim = lastCountChangeMs[s] > pumpOnMs[p] ? STALL_MS : START_STALL_MS;
      if (now - since > lim)
      {
        char why[48];
        snprintf(why, sizeof(why), "no flow on P%d (manual run)", p + 1);
        trip(why);
        return;
      }
    }
  }
}

static void finishRun()
{
  allOff();
  seq = S_DONE;
  logStep("DONE");
  float tot = 0;
  for (int i = 0; i < 3; i++)
    tot += res[i].ml;
  Serial.println(F("\n===== SEQUENCE COMPLETE ====="));
  Serial.printf("Step 1 flush: %.1f mL of %.1f mL to the jug in %.1f s\n", res[L_WATER].ml, res[L_WATER].target, res[L_WATER].secs);
  Serial.printf("Step 2 dT: %.2f C reached after %.1f s\n", dtReached, dtSecs);
  for (int i = 0; i < 3; i++)
  {
    int l = cfg.order[i];
    Serial.printf("Step 3 %-7s target %7.1f mL  metered %7.1f mL  error %+6.1f mL (%+.2f %%)  ratio %.1f %%\n", LD[l].name,
                  res[l].target, res[l].ml, res[l].ml - res[l].target, (res[l].ml - res[l].target) * 100.0f / res[l].target,
                  tot > 0 ? res[l].ml * 100.0f / tot : 0);
  }
  Serial.printf("Total colour %.1f mL, run time %.1f s\n", tot, runSecs());
  Serial.print(F("SAFE STATE: "));
  for (int p = 0; p < 4; p++)
    Serial.printf("P%d=%u%% ", p + 1, pumpPct[p]);
  for (int v = 0; v < NSV; v++)
    Serial.printf("SV%d=%s ", v + 1, valveOpen[v] ? "OPEN" : "closed");
  Serial.println();
  Serial.println(F("=============================="));
  logTemp(true);
  runLogging = false;
  printReport();
  Serial.println(F(">>> All pumps OFF, all valves CLOSED. Press START for a new run (empty the jug first)."));
}

static void enterDose()
{
  if (pumpPct[P_LOOP] || valveOpen[SV_LOOP])
    loopStop();
  seq = S_DOSE;
  logStep("STEP3_START");
  doseIdx = 0;
  if (!startDoseIdx())
    trip("first colour dose would not start");
}

static void enterDt()
{
  seq = S_DT;
  dtT0 = millis();
  dtConfirmN = 0;
  lastTempSeen = tempFrames;
  loopRefT = tempC[0];
  loopChecked = false;
  logStep("STEP2_START");
  if (cfg.dtTarget <= 0)
  {
    Serial.println(F("> STEP 2 skipped (dt set to 0, test mode)"));
    logStep("STEP2_SKIPPED");
    enterDose();
    return;
  }
  if (tempsOk() && deltaT() >= cfg.dtTarget + cfg.dtMargin)
    Serial.printf("> STEP 2: dT is already %.2f C, confirming over %u readings\n", deltaT(), cfg.dtConfirm);
  if (!loopStart())
  {
    trip("cooling loop would not start");
    return;
  }
  Serial.printf("> STEP 2: SV5 open, P4 %u%% circulating YELLOW through the ice-bath coil until |TS1 - TS2| >= %.1f C\n",
                cfg.loopDuty, cfg.dtTarget + cfg.dtMargin);
}

static void seqStep()
{
  uint32_t now = millis();
  switch (seq)
  {
  case S_FLUSH:
    if (dose.ph == D_FAULT)
      break;
    if (dose.ph == D_DONE)
    {
      recordResult(L_WATER);
      logStep("STEP1_DONE");
      Serial.printf("> STEP 1 DONE: %.1f mL flushed to the jug, P1 off, SV4 closed\n", dose.mlFinal);
      Serial.println(F(">>> LIFT THE JUG OUT OF THE MIXING TANK NOW <<<"));
      enterDt();
    }
    break;
  case S_DT:
  {
    if (!tempsOk())
    {
      if (now - dtT0 > 5000)
        trip("temperature sensor missing or not reporting");
      break;
    }
    if (isnan(loopRefT))
      loopRefT = tempC[0];
    if (!loopChecked && cfg.loopCheckS && now - dtT0 > cfg.loopCheckS * 1000UL)
    {
      loopChecked = true;
      float drop = loopRefT - tempC[0];
      Serial.printf("~ cooling check: TS1 dropped %.2f C in %lu s\n", drop, (unsigned long)cfg.loopCheckS);
      if (drop < cfg.loopMinDrop && deltaT() < cfg.dtTarget + cfg.dtMargin)
      {
        trip("no circulation in the cooling loop (TS1 not dropping)");
        break;
      }
    }
    if (tempFrames != lastTempSeen)
    {
      lastTempSeen = tempFrames;
      if (deltaT() >= cfg.dtTarget + cfg.dtMargin)
        dtConfirmN++;
      else
        dtConfirmN = 0;
      if (dtConfirmN >= cfg.dtConfirm)
      {
        dtReached = deltaT();
        dtSecs = (now - dtT0) / 1000.0f;
        loopStop();
        logTemp(true);
        Serial.printf("> STEP 2 DONE: dT = %.2f C (TS1 %.2f, TS2 %.2f) after %.1f s, P4 off, SV5 closed\n", dtReached, tempC[0], tempC[1], dtSecs);
        logStep("STEP2_DONE");
        enterDose();
        break;
      }
    }
    if (cfg.dtTimeoutMin && now - dtT0 > cfg.dtTimeoutMin * 60000UL)
      trip("dT not reached in time");
    break;
  }
  case S_DOSE:
    if (dose.ph == D_FAULT)
      break;
    if (dose.ph == D_DONE)
    {
      recordResult(dose.line);
      if (++doseIdx < 3)
      {
        if (!startDoseIdx())
          trip("next colour dose would not start");
      }
      else
      {
        logStep("STEP3_DONE");
        finishRun();
      }
    }
    break;
  default:
    break;
  }
}

static bool running() { return seq == S_FLUSH || seq == S_DT || seq == S_DOSE || doseActive(); }

static void runStart()
{
  if (running())
  {
    Serial.println(F("! busy"));
    return;
  }
  for (int i = 0; i < NLINES; i++)
    if (cfg.line[i].k <= 0)
    {
      Serial.printf("! %s not calibrated (k=0), run refused\n", LD[i].name);
      return;
    }
  if (!linkOk())
  {
    Serial.println(F("! no data from sensor board U7, run refused"));
    return;
  }
  if (cfg.dtTarget > 0 && !tempsOk())
  {
    Serial.println(F("! temperature sensors TS1/TS2 not both reading, run refused (type temps)"));
    return;
  }
  float need = cfg.line[0].target + cfg.line[1].target + cfg.line[2].target;
  if (mixMl + need > cfg.mixMaxMl)
  {
    Serial.printf("! mixing tank count is %.0f mL, + %.0f mL would pass %.0f mL. Empty it and type mix 0.\n", mixMl, need, cfg.mixMaxMl);
    return;
  }
  allOff();
  jugMl = 0;
  nT = nD = 0;
  tStride = 1;
  tTick = 0;
  for (int i = 0; i < NLINES; i++)
    res[i] = Result();
  dtReached = NAN;
  dtSecs = 0;
  tripWhy[0] = 0;
  runNo++;
  runT0 = millis();
  runLogging = true;
  Serial.printf("\n#RUN,%lu\n", (unsigned long)runNo);
  Serial.printf(">>> RUN %lu START. Step 1 flush %.0f mL water -> jug, Step 2 dT %.1f C by cooling, Step 3 %s %.0f -> %s %.0f -> %s %.0f mL\n",
                (unsigned long)runNo, cfg.line[L_WATER].target, cfg.dtTarget,
                LD[cfg.order[0]].name, cfg.line[cfg.order[0]].target, LD[cfg.order[1]].name, cfg.line[cfg.order[1]].target,
                LD[cfg.order[2]].name, cfg.line[cfg.order[2]].target);
  logStep("STEP1_START");
  logTemp(true);
  seq = S_FLUSH;
  if (!doseBegin(L_WATER, cfg.line[L_WATER].target, true, false, 0, 0))
    trip("flush would not start");
}

static void pollStart()
{
  static bool last = true, stable = true;
  static uint32_t tChange = 0;
  bool r = digitalRead(START_PIN);
  if (r != last)
  {
    last = r;
    tChange = millis();
  }
  if (millis() - tChange > 40 && r != stable)
  {
    stable = r;
    if (!stable)
    {
      if (running())
        trip("START pressed during run (used as stop)");
      else
        runStart();
    }
  }
}

static void handleCommand(String line)
{
  line.trim();
  if (!line.length())
    return;
  char buf[96];
  line.toCharArray(buf, sizeof(buf));
  char *cmd = strtok(buf, " ");
  char *a1 = strtok(nullptr, " ");
  char *a2 = strtok(nullptr, " ");
  char *a3 = strtok(nullptr, " ");
  String c(cmd);
  c.toLowerCase();
  int n = a1 ? atoi(a1) : 0;
  bool busy = running();

  if (c == "help" || c == "?")
    help();
  else if (c == "status")
    printStatus();
  else if (c == "show")
    printConfig();
  else if (c == "temps")
    printTemps();
  else if (c == "cal")
    printCal();
  else if (c == "report")
    printReport();
  else if (c == "start")
    runStart();
  else if (c == "abort" || c == "stop")
    trip("abort command");
  else if (c == "off")
  {
    allOff();
    dose.ph = D_IDLE;
    seq = S_IDLE;
    runLogging = false;
    Serial.println(F("all off"));
  }
  else if (c == "tlog" && a1)
  {
    tlogIdle = n != 0;
    Serial.printf("idle temperature log %s\n", tlogIdle ? "on" : "off");
  }
  else if (busy)
    Serial.println(F("! busy, type abort first"));
  else if (c == "prime" && n >= 1 && n <= 4 && a2)
    doseBegin(n - 1, 0, n == 1 || n == 4, true, (uint32_t)(atof(a2) * 1000), cfg.line[n - 1].fast);
  else if (c == "calrun" && n >= 1 && n <= 4 && a2)
  {
    uint8_t duty = a3 ? atoi(a3) : cfg.line[n - 1].fast;
    doseBegin(n - 1, 0, n == 1 || n == 4, true, (uint32_t)(atof(a2) * 1000), duty);
  }
  else if (c == "k" && n >= 1 && n <= 4 && a2)
  {
    float ml = atof(a2);
    if (ml <= 0 || lastPulses[n - 1] == 0)
      Serial.println(F("! need a calrun or dose on that line first, and mL > 0"));
    else
    {
      cfg.line[n - 1].k = lastPulses[n - 1] / ml;
      if (nC < MAX_C)
        clog[nC++] = {(uint8_t)(n - 1), lastPulses[n - 1], lastRunMs[n - 1], ml, cfg.line[n - 1].k};
      Serial.printf("C,%d,%s,%lu,%lu,%.1f,%.4f\n", n, LD[n - 1].name, (unsigned long)lastPulses[n - 1],
                    (unsigned long)lastRunMs[n - 1], ml, cfg.line[n - 1].k);
      Serial.printf("k%d = %lu / %.1f = %.4f pulses/mL (type code and paste TUNE_K to keep it)\n", n,
                    (unsigned long)lastPulses[n - 1], ml, cfg.line[n - 1].k);
    }
  }
  else if (c == "dose" && n >= 1 && n <= 4 && a2)
  {
    bool jug = a3 && String(a3) == "jug";
    doseBegin(n - 1, atof(a2), jug, false, 0, 0);
  }
  else if (c == "loop" && a1)
  {
    if (n)
    {
      if (loopStart())
        Serial.println(F("cooling loop ON (SV5 open, P4 running). No flow sensor on this loop: watch the coil outlet."));
    }
    else
    {
      loopStop();
      Serial.println(F("cooling loop off"));
    }
  }
  else if (c == "jug" && a1)
  {
    jugMl = atof(a1);
    Serial.printf("jug ~%.0f mL\n", jugMl);
  }
  else if (c == "mix" && a1)
  {
    mixMl = atof(a1);
    Serial.printf("mixing tank ~%.0f mL\n", mixMl);
  }
  else if (c == "valve" && n >= 1 && n <= NSV && a2)
  {
    setValve(n - 1, atoi(a2));
    printStatus();
  }
  else if (c == "pump" && n >= 1 && n <= 4 && a2)
  {
    setPump(n - 1, atoi(a2));
    printStatus();
  }
  else if (c == "save")
    saveConfig();
  else if (c == "code")
    printCode();
  else if (c == "load")
  {
    loadConfig();
    printConfig();
  }
  else if (c == "defaults")
  {
    setDefaults();
    printConfig();
    Serial.println(F("(not saved yet)"));
  }
  else if (c == "set" && a1 && a2)
  {
    String k(a1);
    k.toLowerCase();
    float v = atof(a2);
    int i = k.length() > 0 ? k.charAt(k.length() - 1) - '1' : -1;
    String base = k.substring(0, k.length() - 1);
    bool ok = true;
    if (i >= 0 && i < NLINES && base == "k")
      cfg.line[i].k = v;
    else if (i >= 0 && i < NLINES && base == "tgt")
      cfg.line[i].target = v;
    else if (i >= 0 && i < NLINES && base == "fast")
      cfg.line[i].fast = constrain((int)v, 0, 100);
    else if (i >= 0 && i < NLINES && base == "slow")
      cfg.line[i].slow = constrain((int)v, 0, 100);
    else if (i >= 0 && i < NLINES && base == "ovr")
      cfg.line[i].overrun = v;
    else if (k == "order" && strlen(a2) == 3)
    {
      uint8_t o[3];
      bool seen[3] = {false, false, false};
      for (int j = 0; j < 3; j++)
      {
        o[j] = a2[j] - '1';
        if (o[j] > 2 || seen[o[j]])
          ok = false;
        else
          seen[o[j]] = true;
      }
      if (ok)
        memcpy(cfg.order, o, 3);
    }
    else if (k == "band")
      cfg.bandPct = v;
    else if (k == "bandmin")
      cfg.bandMinMl = v;
    else if (k == "learn")
      cfg.learn = v != 0;
    else if (k == "dt")
      cfg.dtTarget = v;
    else if (k == "dtmargin")
      cfg.dtMargin = v;
    else if (k == "dtconfirm")
      cfg.dtConfirm = constrain((int)v, 1, 50);
    else if (k == "dttimeout")
      cfg.dtTimeoutMin = (uint32_t)v;
    else if (k == "loopduty")
      cfg.loopDuty = constrain((int)v, 0, 100);
    else if (k == "loopcheck")
      cfg.loopCheckS = (uint32_t)v;
    else if (k == "loopdrop")
      cfg.loopMinDrop = v;
    else if (k == "mixmax")
      cfg.mixMaxMl = v;
    else if (k == "jugmax")
      cfg.jugMaxMl = v;
    else
      ok = false;
    if (ok)
    {
      printConfig();
      Serial.println(F("(type code to get the TUNING block)"));
    }
    else
      Serial.println(F("! unknown key or bad value"));
  }
  else
    Serial.println(F("? type help"));
}

void setup()
{
  for (int v = 0; v < NSV; v++)
  {
    pinMode(SV_PIN[v], OUTPUT);
    digitalWrite(SV_PIN[v], LOW);
  }
  for (int p = 0; p < 4; p++)
  {
    ledcSetup(p, PWM_FREQ, PWM_BITS);
    ledcAttachPin(PWM_PIN[p], p);
    ledcWrite(p, 0);
  }
  for (int i = 0; i < 4; i++)
    pinMode(FSW_PIN[i], INPUT);
  pinMode(START_PIN, INPUT_PULLUP);
  Serial.begin(115200);
  Serial2.setRxBufferSize(1024);
  Serial2.begin(LINK_BAUD, SERIAL_8N1, LINK_RX_PIN, LINK_TX_PIN);
  loadConfig();
  delay(300);
  Serial.println(F("\n[U2 controller] Team 13 Chocolate, Day 2: Flush > dT 10 C (cooling) > Dose. Type help.\nEmpty jug in the mixing tank under the red outlet, then press START."));
  printConfig();
}

void loop()
{
  pollLink();
  pollStart();
  interlocks();
  doseStep();
  seqStep();
  logTemp(false);

  static String rx;
  while (Serial.available())
  {
    char ch = Serial.read();
    if (ch == '\n' || ch == '\r')
    {
      if (rx.length())
      {
        pollLink();
        handleCommand(rx);
        rx = "";
      }
    }
    else if (rx.length() < 90)
    {
      rx += ch;
    }
  }
}
